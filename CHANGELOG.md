# 📋 Журнал змін (Changelog)

Усі помітні зміни у проєкті **«Українська озвучка Antigravity»** документуються у цьому файлі.

Формат відповідає принципам [Keep a Changelog](https://keepachangelog.com/uk/1.0.0/), а версіонування базується на [Semantic Versioning](https://semver.org/lang/uk/).

## [1.6.2] — 2026-09-29

### 🎯 Виправлення мобільного відтворення (Web Audio Primary + Touch Fix)
- **Усунуто блокування подвійного тапу / паузи на смартфонах**:
  - Прибрано конфлікт між `touchend` та синтезованим `click` (300 мс затримки), який миттєво ставив звук на паузу через 300 мс після старту.
  - На кнопках відтворення та швидкості залишено чистий нативний `click`, що забезпечує стабільний запуск без розсинхронізації станів.
- **Web Audio API як первинний рушій відтворення**:
  - Аудіобуфер тепер попередньо декодується в пам'ять одразу при завантаженні сторінки (`AudioBuffer`), що усуває асинхронні затримки при кліку.
  - Повне скасування залежності від CSP пісочниці `iframe` (`media-src`) та політики Autoplay — відтворення стартує синхронно в рамках користувацького жесту.
  - Плавне апаратне керування швидкістю мовлення (1.0x, 1.3x, 1.5x, 1.8x) та перемотування.

## [1.6.1] — 2026-09-29

### 🔊 Подвійний рушій відтворення (HTML5 + Web Audio API) для мобільних браузерів
- **Виправлено запуск звуку на мобільних пристроях**:
  - Усунуто проблему блокування `Blob` URL (`blob:null/...`) у sandboxed `iframe` з непрозорим походженням (opaque origin).
  - Впроваджено прямий DOM-елемент `<audio>` з легітимним стандартом MIME `audio/mpeg`.
  - Додано автономний рушій **Web Audio API (`AudioContext`)**: якщо мобільний браузер блокує HTML5 audio через політику пісочниці, плеєр автоматично перемикається на пряме відтворення з декодованого бінарного буфера в пам'яті.
  - Оптимізовано обробники тач-подій (`touchend` + `click` з дебаунсом 250 мс), що гарантує надійний запуск звуку з першого дотику на сенсорному екрані.

## [1.6.0] — 2026-09-29

### 📱 Мобільна підтримка (Remote Web) та радикальна економія токенів
- **Повна підтримка мобільного веб-інтерфейсу (`antigravity.google.com`)**:
  - **MP3 компресія через FFmpeg (64kbps CBR)**: розмір HTML-віджета скоротився з 1.7 МБ до ~33 КБ (на 98%!).
  - **Завантаження аудіо через Blob URL**: усуває блокування довгих Base64 Data URI у мобільних браузерах (Chrome на Android, Safari на iOS).
  - **Precomputed Duration**: точна тривалість вшивається безпосередньо у HTML, запобігаючи зависанню таймера на `0:00 / 0:00`.
  - **Тач-скролінг та адаптивна верстка**: підтримка `touchstart`/`touchmove` для перемотування пальцем, гнучкий `flex: 1` таймлайн для екранів від 300px.
  - **Відмова від зовнішнього Tailwind JS**: 100% самодостатній інлайн CSS (<1.5 КБ), нуль зовнішніх мережевих запитів.
- **Очищення та оптимізація ін'єкції токенів (Token Optimization)**:
  - Стиснуто системні правила до ультракомпактних високоефективних директив (~140 токенів замість ~800).
  - Прибрано дублювання правил у глобальному конфігу `AGENTS.md` (економія ще ~450 токенів).
  - Видалено дублюючі файли у локальній папці `.agents/`.
  - Загальна економія: понад 1,000 токенів контексту на кожному ході діалогу.

## [1.5.1] — 2026-09-29

### 🛡️ Виправлення дублювання плеєра та захист від спаму
- **Суворе правило дедуплікації (Single-Player Enforcement)**:
  - Плеєр вставляється строго **один раз** на фінальну відповідь користувачу.
  - Повністю заборонено вставляти плеєр у проміжні статуси ("Waiting for synthesis...", "Оновлюю плеєр...") або при спрацьовуванні фонових вартових (inbox-ping, cron, healthcheck).
  - Усунуто проблему, через яку в чаті поруч виводилися два однакових аудіоплеєри.
- **Оптимізація імпорту Stanza**:
  - Прибрано зайві мережеві запити на кожному імпорті, якщо кешовані моделі мови вже є на диску.

## [1.1.0] — 2026-09-24

### ⚡ Новий функціонал та оптимізації продуктивності
- **Потоковий плейлист речень (Low Latency Streaming):**
  - Реалізовано архітектуру Producer-Consumer на базі черги потоків.
  - Текст нарізається на окремі речення, і перше речення починає лунати в динаміках уже через 1–2 секунди.
  - Усі наступні речення компілюються паралельно у фоновому потоці під час відтворення поточного.
- **Робота на 100% в оперативній пам'яті (Pure RAM Execution):**
  - Переведено синтез на буферизацію через `io.BytesIO` та відтворення `winsound.SND_MEMORY`.
  - Повністю виключено операції запису/читання з диска (Zero Disk I/O).
  - Жодних тимчасових `.wav` файлів у системних каталогах не створюється.
- **Розумна фільтрація тексту:**
  - Автоматичне вирізання markdown-розмітки, кодових блоків, URL-посилань та спецсимволів перед озвученням.
